**WP Ollama SEO Pro** is a powerful WordPress plugin that integrates with Ollama and other AI APIs to provide comprehensive SEO and AEO optimization for WordPress sites. This is the open-source version for community use and contribution.

## Features

### AI-Powered SEO
- Automatic SEO title and meta description generation
- Focus keyword suggestions
- Schema markup (JSON-LD)
- FAQ generation for AEO/voice search

### Multi-API Support
- Ollama (local AI models)
- Gemini API
- DeepSeek API

### Content Management
- Auto-refresh content
- Auto-posting from topics
- Custom post type support

### Additional Features
- Queue management system
- SEO analysis & reporting
- Glassmorphic admin interface

## Installation

```bash
# Install dependencies
npm install

# Start proxy server
node includes/proxy-server.js
```

Then install the plugin in WordPress.
